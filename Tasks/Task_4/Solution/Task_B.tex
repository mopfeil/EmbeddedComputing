

\subsection*{\Large Motor Control: Rotating }
    \begin{itemize}
        \item  Since the robot has two motors, it means to rotate it left or right, we would need control over the speed and direction of each motor.\\
        Apply separate PWM values to the motors.\\ 
        $\implies$ If we set a higher PWM to the Left Motor(Motor\_1), the Robot moves Right.\\
        $\implies$ If we set a higher PWM to the Right Motor(Motor\_2), the Robot should move Left.\\
        \item Preferably use RPi.GPIO library to implement this functionality.
        \item \textbf{In this Solution  below, the robot circles Left }
        \end{itemize}

    \begin{lstlisting}[language=Python]
    #   IN1: HIGH && IN2: LOW  --> Motor1 Forward
    def Robot_M1_FW():
        GPIO.output(Motor1_IN1, GPIO.HIGH)
        GPIO.output(Motor1_IN2, GPIO.LOW)


    #   IN1: HIGH && IN2: LOW  --> Motor2 Forward
    def Robot_M2_FW():
        GPIO.output(Motor2_IN1, GPIO.HIGH)
        GPIO.output(Motor2_IN2, GPIO.LOW)
    
    # Set HIGHER PWM on Right Motor to move Left
    def Circle_Mov_FWLeft():
    
        PWM_2.ChangeDutyCycle(70)
        Robot_M2_FW()
        PWM_1.ChangeDutyCycle(30)
        Robot_M1_FW()
        time.sleep(10)
        Robot_STOP()
        
    while true :
        led.on()
        if button.is_pressed :
            Circle_Mov_FWRight()
        else:
            Circle_Mov_FWLeft()
        \end{lstlisting}
