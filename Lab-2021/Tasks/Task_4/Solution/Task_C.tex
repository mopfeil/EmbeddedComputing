\subsection*{\Large Motor Control: Speed Control }
    \begin{itemize}
        \item  By changing PWM values of the motors, one can accelerate or decelerate the Robot.\\ 
        $\implies$ A while or for loop should be suitable.
      
        \item \textbf{In this Solution  below, the robot accelerates forward and then decelerates}
        \end{itemize}
